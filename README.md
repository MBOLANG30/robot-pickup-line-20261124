One pickup line in the voice of a robot trying to charm someone: a machine with no heart whose own diagnostics keep flagging its crush as critical. The joke grows out of being a machine — diagnostics, not a human line with a beep pasted on — and it lands in 66 characters.

## Run it

```sh
node main.ts
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset), with no trailing newline.
